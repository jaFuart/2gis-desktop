# Qt and Qt for Python

The standalone desktop builds include shared Qt 6.10.3 libraries and the
PySide6 Essentials and Shiboken6 bindings from the official Qt Python wheels.
These components are used under the GNU LGPL version 3 where offered by Qt.
Their copyright and license notices are supplied by the Qt project.

- Qt source: https://code.qt.io/cgit/qt/
- Qt for Python source: https://code.qt.io/cgit/pyside/pyside-setup.git/
- Versioned Qt source archives: https://download.qt.io/archive/qt/6.10/6.10.3/
- PySide6 Essentials release: https://pypi.org/project/PySide6-Essentials/6.10.3/
- Shiboken6 release: https://pypi.org/project/shiboken6/6.10.3/
- GNU LGPL v3: https://www.gnu.org/licenses/lgpl-3.0.html
- GNU GPL v3: https://www.gnu.org/licenses/gpl-3.0.html

The application and Qt libraries are distributed as separate files in the
desktop package. Users may replace the Qt libraries with compatible versions
and exercise the rights granted under the LGPL, including debugging their
changes to the libraries.
